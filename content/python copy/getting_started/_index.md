### Let's open your workspace

For this workshop, we will be using a web-based workspace to code in Python. The workspace can be accessed through this link: [She Codes Jupyter](https://shecodesjupyter.netlify.app/).
The work created on this will remain private to you, and is saved through browser data. Should you decide to delete your browser data, your work will be lost if not locally saved.

This workshop not require any installations of Python or Visual Studio Code.
